## 🧠 About Me

I'm an **AI Agents Engineer** focused on building autonomous systems that automate prospecting, sales, customer service, and back-office operations for modern businesses. I architect production-ready agents using **Python**, **Claude Code**, and **LLM APIs**, deploying them on Linux VPS infrastructure with CI/CD via GitHub Actions.

My edge: I don't just build chatbots — I ship **autonomous business operators** that work 24/7, replacing entire workflows with reliable, observable, and scalable AI.

🌍 Fluent in **Portuguese**, **English**, and **French**.

### 🌳 [oaken-agentes](https://github.com/isaac-carvalho/oaken-agentes)
> A collection of **25 production-grade AI agents** designed for real business use cases — lead generation, sales automation, customer support, content ops, and internal process automation.

**Stack:** `Python` · `Claude API` · `OpenAI API` · `LangChain-style orchestration` · `FastAPI` · `Linux VPS` · `GitHub Actions`

**Highlights:**
- 🤖 Multi-agent orchestration with tool-use and memory
- 📈 End-to-end pipelines for prospecting and outbound sales
- 🛎️ Conversational agents for support and qualification
- ⚙️ Self-deployable on any Linux VPS with one command
